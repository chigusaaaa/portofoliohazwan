Tentang Saya

Latar Belakang

Saya Hazwan Fahmi Ghailan, mahasiswa Teknik Informatika yang fokus pada pengembangan web, pembuatan perangkat bantu berbasis Python, desain UI yang bersih, serta oprek sistem Linux.

Saya senang membangun tools praktis yang memangkas pekerjaan manual berulang—seperti otomasi penyusunan dokumen dan konversi format tulisan akademik—sambil menjaga kode tetap rapi dan mudah dikembangkan.

Di luar proyek, saya mengerjakan praktikum Pemrograman Web (Laravel), Basis Data Lanjut, dan Jaringan Lanjut (MikroTik), merakit desktop Linux sendiri dengan CachyOS dan Hyprland, serta menjalankan layanan self-hosted lewat Docker dan Tailscale. Saya juga berkarya sebagai kreator dengan nama chigusa.
